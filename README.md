# Salary Prediction API

End-to-end ML project predicting software developer salaries.

## 🚀 Live API
https://your-render-url.onrender.com/docs

## 🛠 Tech Stack
- Python
- Pandas
- Scikit-learn
- FastAPI
- Render (Deployment)

## 📊 Model
- Linear Regression
- Log transformation
- Cross-validated R² ≈ 0.43

## 📦 Features Used
- YearsCodePro
- Country
- EdLevel
- Employment
- DevType
- OrgSize

## ▶️ Run Locally

pip install -r requirements.txt
uvicorn app:app --reload
